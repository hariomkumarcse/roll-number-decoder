About this project

Many colleges encode meaningful information directly inside a student's roll number — the year they were admitted, which institution and branch they belong to, and their sequence within that batch.

Roll Number Decoder takes a 13-digit roll number and breaks it into those four parts:

Digits 1–2Academic year
Digits 3–6College code
Digits 7–9Branch code
Digits 10–13Serial number

This project started as a plain Core Java command-line program and is being rebuilt step by step into a full-stack Spring Boot application, as a hands-on way to practice REST APIs, JPA/MySQL persistence, and server-rendered Thymeleaf pages.
